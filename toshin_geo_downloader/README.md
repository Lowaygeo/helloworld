# 東進過去問：各大學「地理」近五年考古題下載工具（Windows）

在**你自己的電腦**上執行。帳號密碼由你在瀏覽器中親自輸入，不會經過程式或 Claude。

## 第一次準備

1. 安裝 Python 3：https://www.python.org/downloads/
   安裝畫面最下方記得勾選 **Add python.exe to PATH**。
2. 下載這個資料夾（`toshin_geo_downloader`）到電腦，例如放在桌面。

## 執行

1. 雙擊 `run.bat`。第一次會自動安裝套件（需要幾分鐘）。
2. 會跳出一個瀏覽器視窗 → 在裡面**登入東進過去問網站**。
3. 登入完成後，回到黑色視窗按 **Enter**，程式開始自動瀏覽並下載。
4. 下載結果在 `地理過去問\大學名\年度\` 底下，另有 `地理過去問\清單.csv` 列出全部檔案。

預設條件：2022–2026 年度、科目含「地理」、**排除共通テスト／センター試験**。
每次請求間隔 2 秒，數百所大學可能要跑數小時，期間電腦不要睡眠。
中途關掉也沒關係，再雙擊 `run.bat` 會從上次進度繼續。

## 進階選項（在命令提示字元中執行）

```
run.bat --from-year 2021 --to-year 2025     改年度範圍
run.bat --keep-unknown-year                 看不出年度的地理 PDF 也下載（放在「年度不明」）
```

## 下載不到檔案時

程式是依「連結文字／所在表格列含有『地理』與年度」來判斷，網站結構若不同可能抓不到。
請把 `地理過去問\_debug` 資料夾（存了前 30 頁的網頁原始碼，不含密碼）傳給 Claude，
我會依實際網頁結構調整程式。

## 注意

- 請先確認網站使用條款是否允許此類下載；下載內容僅供個人備課使用，請勿公開散布。
- `地理過去問\_browser_profile` 內存有你的登入狀態，**不要上傳或分享這個資料夾**。
